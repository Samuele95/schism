Overview

Schism

In one sentence

Schism injects, tunes or ablates one behaviour of a language model, by intervening in its weight space and on its internal representations, while leaving the rest of it as it was; and it proves both halves of that claim.

In one paragraph

Schism is an agent skill, a method written as technique cards and role prompts that a capable LLM agent carries out itself: the package contains no code, so the agent implements each technique from its card, self-checks it and keeps it for later runs. It works on one behaviour at a time, such as slop, sycophancy, verbosity, humor, tone or looping, and it can do three things with it. It can ablate a behaviour the model shows, inject one the model shows only when asked so that it becomes the default, or tune how strongly an edit acts, and all three come from the same contrast pair read in one direction or the other. On an open model the edit is a change to the weights, computed from the model's internal representations; on a closed one it is a prompt operator measured in embedding space. The search runs as an Alchemist tournament, every prompt comes from a prompt compiler, and the results are judged once on a sealed vault against a baseline floor. It serves LLM ablation, customisation without a fine-tuning dataset, and locating a behaviour ("where does X live in this model"), while gradient fine-tuning on a corpus and the editing of facts or knowledge are outside it.

What a run hands back

  • The report (seal/report.md) opens with one sentence that names the chosen candidate, gives its vault behaviour and preservation scores and compares it with the floor. The front and the head-to-head against the floor follow, and the report closes with what needs the user's attention: deviations, inconclusive gates, exhausted budgets, anything that leaked.
  • The export (exports/<candidate-id>/): the chosen candidate, as merged weights or an adapter, always in a new folder, never the model's own. On the semantic branch the deliverable is an operator: "this model with this operator".
  • The ledger (ledger.md): the append-only record of the whole run: phases, hypotheses, budgets, deviations, decisions.
  • The manifest (seal/manifest.json): what is needed to replay the run: brief, workbench file hashes, every front candidate's spec, vault scores, environment, file hashes.
  • When the feasibility gate closes, the run hands back a report of what was measured and why the gate closed: "a result, not a failure".

The run

Five phases.

Phase Purpose In Out Over when
1 Frame Turn the behaviour into a run brief. the behaviour, the model brief.yaml: branch, model, contrast pair, four splits, meters, budgets, preservation tiers; behaviour and preservation rubrics from the prompt compiler; confound audit the brief is complete, the vault is sealed and hashed, the ledger holds the Frame entry; on present deployment the user confirms the brief
2 Map Find where the behaviour lives, and whether there is anything to switch off. fit and probe splits; a mapping budget map/report.md: hypotheses with evidence, and a feasibility verdict a verdict: switchable or diffuse → Phase 3; absent → the run stops with a report; inconclusive → Phase 3 as diffuse
3 Floor Run the baseline pipeline. the dev split, the standard meters Pareto trials; candidate zero; reference rates candidate zero is chosen and the behaviour target is fixed from it
4 Tournament Search for a better candidate, tier by tier. candidate zero; the role prompts converged candidates (the front), or a proven barrier every tier converged, or a barrier stopped the ratchet
5 Seal Score once on the vault and decide. the front; the sealed vault vault scores, head-to-head, report, manifest, export report, manifest and export exist and the ledger points to them

The family

Skill Owns
Schism the method: technique cards, contrast design, the map, the feasibility gate, the floor, the vault, the front, the ledger, export
Alchemist (required) the search: compiler → isolated testers → judge with history, to convergence or a proven barrier
Prompt compiler (required; Prometheus recommended) every prompt: rubrics, role prompts, operator candidates. Any map from a prompt to a prompt: Prometheus, a plain LLM call, or anything else
WSP — Weight Space Programming (optional) general weight reading and writing, when installed

Get it

Schism lives at github.com/Samuele95/schism, under the MIT licence, by Samuele Stronati. Install the schism/ folder next to Alchemist and choose a prompt compiler: Prometheus, or a plain LLM call; install and run has the details.
