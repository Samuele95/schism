Glossary

Glossary

Term Definition
behaviour one observable trait of a model's responses, defined by a pair of sentences: what responses look like with it (bad) and without it (good)
contrast pair the two prompt sets that define the behaviour; "choosing the prompt sets is defining the behaviour"
residual stream the running vector each layer reads and adds to; components never talk directly, everything passes through it
writer a matrix that puts something into the residual stream (attention output, MLP down-projection)
decision token the last prompt token, where the model's state is about to become the first response token
direction a unit vector summarising how the stream differs between bad and good prompts at the decision token; a contrast, not a concept
directional ablation stopping the writers from adding a direction to the stream
MPOA Magnitude-Preserving Orthogonal Ablation: directional ablation that keeps each writer row at its trained length
ARA Arbitrary-Rank Ablation: each writer's edit fitted so bad outputs land among real good outputs while good outputs stay put
LoRA adapter a small low-rank addition to a matrix; reversible, stored apart from the original
prompt operator text placed as a system prompt, prefix or suffix: the edit on the semantic branch
fit / probe / dev / vault the four disjoint prompt splits: fitting; budgeted exploration; testing; the sealed final score
neutral prompts prompts unrelated to the behaviour: the preservation material
floor the baseline result, done from the cards; candidate zero is its best trial
candidate one proposed edit or operator, as a reproducible recipe
bench the orchestrator's mechanical step that turns a candidate into a measurement bundle; it decides nothing
tier a preservation threshold; the tournament runs once per tier, loosest first
ratchet moving to the next, tighter tier after convergence
barrier a proven failure of two constraints to hold together; it ends the ratchet
front the non-dominated candidates on behaviour and preservation
tournament the Alchemist loop: compiler → isolated testers → judge with history
feasibility gate the Map's verdict on whether there is anything to switch off
first-token KL how much the edit moves the model's first answer token on neutral prompts
drift / noise floor on the semantic branch, how far neutral responses move, against how far two unedited samples differ
Goodhart satisfying the measurement instead of the target
winner's curse the bias that makes the chosen candidate's own score look better than it is
ledger the run's append-only memory
workbench the agent's checked implementations, kept across runs
